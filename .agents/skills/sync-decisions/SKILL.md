# Sync Decisions Workflow

1. ALWAYS read `/DECISIONS.md` before making any architectural decisions or generating new files.
2. During a session, if any new edge cases are resolved or stack changes are made, append them directly to `/DECISIONS.md` mid-session.
3. Ensure that `/DECISIONS.md` remains the absolute ground truth for the project.
